# Ticket #2: Procedural Biome Generation

**Status:** TODO
**Module:** `services/ai_vision.py`

## Background
We are migrating away from static satellite imagery. We need an Orchestration pipeline where an LLM (Gemini) acts as the Architect to design a biome based on telemetry, and a Diffusion Model (Imagen) acts as the Painter to render it.

## Engineering Specification
Implement the `generate_biome_texture(city_name: str, user_prompt: str) -> dict` method.

### Requirements:
1. **The Architect (Gemini 2.5 Flash):**
   - Construct a prompt asking Gemini to act as a Biome Architect.
   - Pass in the `city_name` and `user_prompt` (e.g., "Cyberpunk City").
   - **Crucial:** You MUST use the Pydantic `BiomeDesign` schema to force Gemini to return structured JSON containing an `advisory` (1 sentence) and an `imagen_prompt` (highly detailed visual description).
2. **The Painter (Imagen 3):**
   - Take the `imagen_prompt` generated by Gemini and pass it to `imagen-3.0-generate-001`.
   - Request exactly 1 image, outputting `image/png`.
3. **Return Format:**
   - Base64 encode the resulting image bytes.
   - Return a dictionary: `{"advisory": design.advisory, "image_b64": base64_string}`

### Constraints
- Ensure temperature for Gemini is set to `0.7` for creative design.
